# REQ-210 Text Tool group

## Contract and scope

Text is now a workspace Tool. A normal click activates its last variant; holding
for 450 ms opens the two-item Horizontal Text / Vertical Text menu. The slot
shows the variant and a group marker. Down/Right opens the menu from keyboard
focus; Up/Down/Home/End navigate; native Enter/Space activate; Escape cancels
and preserves the previous Tool. Last variant remains app state, outside JSON,
document revision, dirty tracking and Undo/Redo.

A primary Canvas click creates independent Text at the artboard-space press
point on pointer release. Movement beyond six CSS pixels, pointer cancellation,
lost capture, blur, visibility loss, Escape or a structural render discards the
pending click. Dismissing the menu with a Canvas press consumes that press.
Space/middle-button navigation retains its existing path. Active text/IME,
uncommitted fields and other live edits block Tool activation before field blur.

The existing DOM-free `create-artwork` Session command accepts optional
`writingMode` for Text, validates it atomically and sets it during creation.
UI and headless adapters use the same command; no second UI mutation was added.
Omission retains horizontal creation. The existing Inspector direction controls
remain unchanged. Changing a Tool variant never converts existing Text or its
body, font, styles or parameters. Other Rail creation commands are outside this
slice.
