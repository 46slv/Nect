# Polar Transform / 極座標変換

Add Node から `極座標` / `Polar Transform` で検索します。パスの座標を変換するノードで、画像ピクセルのフィルターではありません。

## 接続

Rectangle / Curve → Resample Path → Polar Transform → Fill → Output。
[帯をリングへ変換する編集用サンプル](../examples/polar-transform-ring.json) と [SVG](../examples/polar-transform-ring.svg) を参照してください。

## パラメータ

- Origin: 変換前の矩形領域の左上。
- Width: X 方向のこの幅を一周に対応させます。
- Height: Y 方向のこの高さを Radius に対応させます。
- Center: 変換後の円の中心。
- Radius: Height に対応する半径。
- Angle: 開始角。0° は右、正は時計回り、既定 −90° は上。
- Inverse: 円形から矩形への逆変換。

JSON はノードとパラメータを保持し、Undo/Redo が使えます。SVG/PNG は評価後のパス形状です。色・グラデーションの座標そのものは変換しません。

## 近似と制限

Bézier のアンカーと絶対制御点をそれぞれ変換します。曲線の内部まで厳密に非線形変形するものではありません。四隅だけの矩形をそのまま一周させると頂点が重なるため、通常は上流に Resample Path を入れます。

Inverse は角度の継ぎ目を跨ぐ制御点・線分を拒否します。無断で長い横線に変えたり、輪郭を分断したりしません。元パスを分割するか、Angle を変えて継ぎ目を移動してください。中心の角度は0として扱います。負の半径は拒否します。幅・高さ・半径は 0.0001–100000 px、開始角は ±360°、最大10,000輪郭／100,000点です。

本機能はベクトル版の有界実装です。画像の極座標化、任意の継ぎ目の自動分割、正確な曲線内部変形は含みません。
