## Bounded contract

- Add optional integer `intersect_color_component_index` to the read-only desktop `analyze_regions` request and formal `nect_analyze_regions` schema. Omission preserves the exact D9 response. Presence requires `include_color_groups:true` and `include_color_components:true`; otherwise reject `INVALID_REQUEST`. Reject Boolean, fractional, negative and out-of-range values as `INVALID_REQUEST`, with no partial result. The index selects a D9 component **in this same request** after all D1–D9 checks; it is not an authored or cross-request identifier. Existing exact identity, revision, gesture, scale and threshold validation remain.
- Compute `selected D9 component ∩ D7 mask_boolean` from their already returned row-major maximal horizontal runs on the same committed transparent Canvas output. The D7 mask is its existing dilation-minus-erosion result; no new morphology, renderer, color conversion, saved mask or Session command. Intersection uses half-open horizontal intervals on equal rows and emits maximal row-major runs. Result area is the sum of widths. The two bounded operands have at most 20,000 runs each, so their intersection has fewer than 40,000 runs; no new independent output cap is needed.
- Return `color_component_mask_intersection` with `{operation:"intersection",component_index,rgb,other_operand:"mask_boolean",coordinate_space:"artboard-output-pixels",width,height,source_revision,area,runs}`. Enclosing threshold, scale, color/alpha domain and source revision apply. The result is a transient derived candidate. Empty intersection returns area 0 and empty runs. Omitted request retains all previous fields and refusal precedence. Success/refusal changes no Document, revision, History or native bytes.

## Independent positive and negative oracles

1. A fully opaque 5×5 output with all pixels red except a blue center `(2,2)` has one alpha region, red area 24 in one 4-connected component and blue area 1 in another. D7's mask Boolean is the outer 5×5 one-pixel ring (area 16). Selecting red yields that exact ring: `{0,0,5}`, `{1,0,1}`, `{1,4,1}`, `{2,0,1}`, `{2,4,1}`, `{3,0,1}`, `{3,4,1}`, `{4,0,5}`; selecting blue yields empty. Since RGB sort places blue before red, the red component index is 1 and blue is 0. The computed result must not merely return the entire D7 mask or the entire color component.
2. A two-color output with a separate red island tests that only the selected component participates, not every pixel with the same RGB key. Test no component, out-of-range, negative, fraction, Boolean and missing/false opt-ins. An invalid selection leaves no result and no state change. Preserve D1–D9 earlier-cap precedence by checking an existing D8/D9 over-limit fixture with the new selector present.
3. Check the pixel helper and actual committed Canvas/API output from an embedded exact-color fixture; compare a nonempty direct API result with formal MCP and check native/Document/revision/History preservation. Automated Qt/API/MCP evidence does not close hands-on GUI acceptance.
