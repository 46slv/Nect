# R05-C — first editable Text-on-Path consumer

Status: Sol-frozen implementation packet, 2026-09-27. Baseline: `codex/practical-alpha@d2ccd8f04a1dbe776ee3702ccb49fe7c0041bce4`. Authority: Confirmed [REQ-17](https://app.notion.com/p/3e0fd279a6f3816bb9f8e00cb433216a), Confirmed [REQ-18](https://app.notion.com/p/3e0fd279a6f381e4b014e998de59c467), Accepted [DEC-6](https://app.notion.com/p/3e0fd279a6f3812182d3d5342407849d), P05-B/C in the [Worker packet](https://app.notion.com/p/3e3fd279a6f381ee8ab0ea5ea614c006), [R05-A](r05-a-text-coverage.md) and [R05-B](r05-b-path-sampling-contract.md). This is the first real Text consumer of the common sampling contract. It does not close all of REQ-17/18 or R05.

## Accepted first slice

- Keep `TextSource.content`, family, locale, style, parameters, drivers, object ID and transform authored. Add one optional retained `path_attachment` to `TextSource`: `{path, contour, start_mode, start, spacing, reversed}`. `path` is a Path object ID and `contour` is its authored Contour ID in the same Composition. `start_mode` is `distance` or `normalized`; `start` is a finite du96 distance or finite fraction; `spacing` is a finite nonnegative du96 gap added between shaped glyph advances; `reversed` is boolean. The existing Text `alignment` (`start`, `center`, `end`) anchors the whole shaped span at `start`. The field is absent when detached. No name/index lookup or generated primitive contour is accepted.
- Scope is horizontal, automatic, one-line editable Text, including Japanese and Latin in left-to-right shaped runs. Reject vertical, frame, hard line breaks and RTL runs on attachment or a later edit that would violate this subset. Do not substitute unshaped codepoints for DirectWrite glyphs. Other font coverage remains R05-A. Text using unsupported path modes fails explicitly; it does not silently render as ordinary Text.
- Reuse DirectWrite's shaped glyph IDs, advances, offsets and supported monochrome outlines. Retain derived per-glyph contours for this projection only. For glyph `i`, sample the selected path at the glyph advance midpoint, orient its intact local outline by the forward tangent, and offset its baseline origin by half its advance along that tangent. Preserve whitespace advances even without contours. Existing font fallback and unsupported color-only glyph errors apply. All output remains derived; native never replaces content with outlines.
- Start offset is an anchor on the evaluated contour. `start` alignment puts the first advance at that anchor, `center` centers the full advance-plus-spacing span there, and `end` puts the final advance there. On an open contour the entire span, including whitespace, must fit in `[0,L]`; otherwise reject the edit or evaluation with a stable overflow error. On a closed contour finite starts wrap, but a span greater than `L` rejects instead of overlapping a second lap. The default attachment uses distance 0, spacing 0, forward traversal and start alignment. Detach removes only the attachment; unchanged authored Text origin/transform define the normal Text position on return.
- Apply [R05-B](r05-b-path-sampling-contract.md) exactly: evaluate authored Path point values before its Shape stack, transform cubic controls into Composition space, sample deterministic adaptive arc length, then map the rigid glyph contour into the Text object's local plane with an invertible world affine. Use a world-space length tolerance of at most 0.05 du96 and a deterministic cap (maximum subdivision depth 20 and 4096 leaves per contour); reject on budget exhaustion or nonfinite/zero length. Compare curved sampling to an independent high-resolution oracle to within 0.1 du96. A straight `(0,0)` to `(200,0)` path and its vertical edit/90-degree source transform must match R05-B's exact distance/tangent oracles. The sampler is invoked by this Text projection and remains usable for later Group/part work.
- Evaluation must flow through the shared `evaluate_shape`/Scene projection used by Canvas, bounds, SVG and API. `text_layout` must disclose attachment status and any explicit unsupported/overflow error; it must not report normal flat bounds as attached bounds. Hidden source Path remains a valid reference. A singular Text world inverse, stale Path/Contour ID, cross-Composition reference, unsupported generated source, invalid sample, source deletion, or transform cycle rejects without partial authored state. `DeleteObjects` may delete Path and all dependent Text objects in one atomic batch; deleting only a referenced Path rejects. Rename/reorder do not retarget. When duplicate includes both Path and Text, remap both Path and Contour IDs; copying Text alone retains the original Path/Contour IDs. When a copied Path alone is made, original Text stays with original Path.

## Native, command and UI boundary

- Advance native writer to **0.24** with a strict `schemas/native-v0.24.schema.json` and matching codec. `path_attachment` is optional and legal only at native 0.24 or later. Native 0.1–0.23 migration yields detached Text without changing IDs, text or geometry. Keep `TextSource.version=1`; the document format version gates this optional field. A 0.23 document carrying it is rejected. Validate referential meaning after decode, not merely JSON shape. Native save/reopen retains the exact IDs, numeric mode/value, spacing, reversed flag and authored Text.
- Use the existing `CreateText`/`UpdateText` Session candidate and revision gate, or a thin explicit attach/detach command that calls the same candidate path. JSON-lines/API and Desktop Inspector must be able to attach by explicit Path/Contour IDs, change start mode/value, spacing, reversed and alignment, and detach. Desktop shows eligible same-Composition authored Path contours by stable ID, with an explicit contour choice even when there is only one. It surfaces refusal; no display-only state. No second renderer or editor state.
- Validation and history equality/size accounting must include the new authored field. Failed attach, stale revision, invalid path edit or deletion preserves the Document, revision and Undo history. One successful attach, edit, detach and path edit each have one Undo/Redo step. Cold reopen and recovery are distinct checks.

## Acceptance oracles

1. API creates authored Path and Text, attaches to exact IDs, changes path `(0,0)→(200,0)` to `(0,0)→(0,200)`, and reads transformed glyph geometry in Canvas-equivalent Shape/SVG projection without altering authored content. Verify straight, reversed and closed seam positions against R05-B, then curved samples against the independent oracle. Confirm source transform and Text inverse behavior.
2. Text content and font size edits recompute shaped glyph placements. Mixed Japanese/Latin and a ligature-capable Latin fixture retain DirectWrite glyph count/advances. Test unsupported vertical/frame/multiline/RTL and open-path overflow as explicit errors. Do not claim general feature/format coverage.
3. Test wrong-kind, missing, stale, cross-Composition and generated contour IDs; zero/nonfinite path; singular inverse; source deletion; duplicate/remap; cycle; stale revision; and a failed multi-command batch. Read back unchanged document/revision/history after every failed command.
4. Verify native 0.23 migration to detached state, native 0.24 round trip/cold reopen, JSON-lines command parity, one Desktop Inspector attach/edit/detach flow, Undo/Redo, and SVG output with unchanged native editable source. If owned GUI control is unavailable, record only that exact UI row as `LOCAL_WAIT`; semantic code/API/native acceptance may continue.

## Residuals

Multi-line/frame and vertical Text-on-Path, RTL/bidi run behavior, multi-contour traversal, clipping/repeat overflow policies, variable font/feature controls, deform mode, and Group/part rigid/deform consumers are separate R05 packets. The first slice is not full REQ-17, REQ-18, P05-C/D, R05 or L2 acceptance. R04 Collection scope remains the independent [local design gate](r04-collection-scope-gate.md).

## Implementation and verification, 2026-09-27

The first slice is implemented in the shared Session/Text/Shape projection, native 0.24 codec and strict schema, JSON-lines API and Desktop Inspector. The authored Text content, source and selected Path/Contour IDs remain native; Canvas and SVG consume derived glyph contours. The independent 200,000-step curved oracle, exact straight/closed/reversed/knot cases, mixed Japanese/Latin DirectWrite shaping, old-native migration, cold file reopen, duplicate/remap, source deletion, failed-batch atomicity, unsupported modes, and GUI Inspector attach/detach are exercised in the contract tests. `cmake --build build --config Release` passed; `ctest --test-dir build -C Release --output-on-failure -j1` passed 41/41 before the final additional negative cases; the focused `text_authoring_contract` passed after those cases. The Qt `window_interaction` test uses the test host and is evidence for the implemented UI path, not a hands-on Windows usability acceptance.

The hands-on Text-on-Path creation/edit/save/reopen recipe is `LOCAL_WAIT`: the current Computer Use host capability did not expose a controllable Nect window. Resume this exact row when an owned controllable Nect Desktop window is available; verify visible selection, contour choice, edit, save, cold reopen and detach. No whole REQ-17/18, P05-C or R05 completion is claimed from this slice.
