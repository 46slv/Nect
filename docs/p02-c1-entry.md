## Frozen behavior

1. The existing Document/Session owns authored geometry. Canvas freezes moving stable IDs, same-Composition candidate IDs/geometry, active Composition, entered Group scope, zoom, session identity and starting revision when a drag starts. Preview is transient. Escape/return-home creates no history; a valid release is one Undo. A concurrent API edit, Undo or document/session switch rejects stale release and discards the preview. Do not rebase or resend blindly. Object movement uses the shared `TranslateObjects` solver, including the single-object path; point edits target only selected stable point IDs through existing Point Edit ownership for generated points. Singular world-to-local inverse, driven selected axis, cross-plane or structurally overlapping Group/child selection fails atomically.
2. Compute X and Y correction independently in **logical screen pixels**: `abs(correction * start_zoom) <= 6`, inclusive, independent of DPR. Choose minimum absolute correction first. Only exact equal distances use priority `Guide > Grid > Artboard > Text baseline > object edge > object center > equal-gap`; then lexicographically stable target ID; then fixed source-feature order min/center/max (Grid lines ascending coordinate, boundary before center). No epsilon promotes a near tie. Both axes can win. Feedback visibly names type, stable target and source/target feature, including hidden overlay candidates. If no candidate qualifies, use raw drag delta and no feedback.
3. Guide candidates are Composition axis/position; Grid candidates use explicit Artboard-local bounds projected to Composition, including rectangle edges, cell edges/centers and gutter boundaries. The overlay visibility booleans and Guide/Grid Snap enable booleans are independent per-window view state. Hidden Guide/Grid with Snap ON still qualifies; visible with Snap OFF does not. Hidden objects are never object targets. Missing authored layouts yield no fabricated candidates. Do not clip objects to a Grid. Exact numeric/API values and keyboard nudges remain unsnapped; no momentary modifier is required.
4. Object edge/center uses actual evaluated geometric bounds in the same Composition/entered Group scope, excluding moving objects, effective followers and hidden objects. Text baseline is the actual first-line layout metric in Composition coordinates only for horizontal axis-aligned text. For multi-line text use only line one; rotated/vertical text offers no baseline. Glyph-box bottom is never a baseline substitute. Two-sided equal-gap candidate: left neighbor right edge `L1`, right neighbor left edge `R0`, moving width `w`, target left `(L1+R0-w)/2`; offer only for nonnegative resulting gaps and same Composition. Do not substitute center distribution. One-sided repeated-gap remains a separately specified residual.
5. Native writer stays 0.14; Snap toggles and feedback are view state, never native/recovery/export authored state. No new core command, semantic JSON mutation, migration, or exported overlay. The ordinary `REVISION_CONFLICT`, singular/driven/invalid selection errors remain visible; failed previews/commands do not alter Document, revision, redo cursor or recovery. Save/reopen retains only the accepted authored position, with Guide/Grid IDs stable; a hidden overlay does not change saved definitions.
