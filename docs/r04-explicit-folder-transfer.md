## Contract

Expose “Move selected to Folder…” in Edit and the selection menu. The source is an ordered prefix or suffix of one Folder's whole-object children. Offer only sibling destination Folders in the same Composition for which every intervening sibling is an empty, visible, neutral Folder without driven opacity or effects. Moving toward a later Folder requires a source suffix; moving toward an earlier Folder requires a source prefix. If the whole source is selected, either direction is eligible. The chooser identifies a destination by stable ID as well as name; cancellation changes nothing. A drawable, nonempty or non-neutral intervening sibling is a paint-order barrier and is never offered. If no destination qualifies, refuse with a scoped order/selection error. Point, mixed-parent, middle and noncontiguous selections refuse without authored changes.

Compose existing `MoveOut`, `ReorderObjects` when needed, `PutInside`, and destination child reorder for an earlier destination in **one** `Session::apply` edit. Retain source and destination Folders, object IDs, authored non-transform properties, references, Collection membership, world transforms, evaluated values and flattened paint order. Existing appearance, singular/dynamic transform, dependency and revision guards apply. Do not change native schema or add a structural command; JSON-lines clients can submit the same command sequence atomically. A failed command leaves Document, revision, History and recovery unchanged.

## Oracle and residual

Later: roots `F1,E,F2`, F1 children `A,B`, empty E, F2 child `C`; moving suffix `B` yields F1 child `A`, F2 children `B,C`, with root order unchanged. Earlier: roots `F1,E,F2`, F1 child `A`, F2 children `B,C`; moving prefix `B` yields F1 children `A,B`, F2 child `C`. In both cases, verify identical rendered pixels, flattened paint order, world coordinates, evaluated properties, stable references and Collection membership, exact one-step Undo/Redo, native roundtrip and independent cold reopen. Negative fixtures cover a nonempty intervening Folder, an intervening drawable, unsafe destination, point/middle selection and stale revision.

This packet does not define an appearance-changing move across painted siblings or a cross-plane move. That exact edge remains a local `DESIGN_GATE`: a future interaction must explicitly choose changed paint order or a documented conversion, or refuse; neither is silently inferred here.
