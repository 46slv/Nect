# R05-B — path sampling contract for retained Text and parts

Status: Sol-frozen geometry contract, 2026-09-27. Authority: Confirmed [REQ-17](https://app.notion.com/p/3e0fd279a6f3816bb9f8e00cb433216a), Confirmed [REQ-18](https://app.notion.com/p/3e0fd279a6f381e4b014e998de59c467), Accepted [DEC-6](https://app.notion.com/p/3e0fd279a6f3812182d3d5342407849d), and [P05-B](https://app.notion.com/p/3e3fd279a6f381ee8ab0ea5ea614c006). This freezes the common geometry meaning for an initial real consumer; it does not implement Text-on-Path or imply whole Requirement acceptance.

## Source and space

- A path attachment addresses a **Path object ID and authored Contour ID** in the same Composition as its consumer. Names and contour array positions are not identities. The first slice uses authored Path contours, including evaluated point values and Point Edit corrections. Generated primitive topology, Offset output, Repeater copies, Text outlines and mask geometry are excluded until they have a stable source address contract. A multi-contour Path requires an explicit contour ID; there is no implicit first-contour fallback.
- Evaluate that contour before the paint/Shape stack, then apply the source object's resolved world affine to every cubic control point. Arc length and tangents are in the Composition coordinate plane, after transform. A source transform edit therefore recomputes placements. A consumer converts samples into its own local space only after a valid inverse exists; a singular inverse must refuse rather than silently change coordinates. Cross-Composition sampling is unsupported without an explicit conversion contract.
- Sampling is a pure projection of the exact authored revision. It does not create objects, mutate source points, allocate persistent generated IDs or commit an edit. A retained attachment in the later consumer must keep the source object/contour IDs and mode values in native state; Canvas, SVG and API must use the same projection.

## Parameter and numeric behavior

- Expose distance in `du96` and normalized fraction as two explicit modes. Normalized input is converted to distance using the evaluated total contour length at that revision. It is never stored as a resolved world coordinate. Open contours accept distance in `[0,L]` and normalized in `[0,1]`; out-of-range requests fail. Closed contours wrap finite distance modulo `L`; normalized `1` maps to the start. The caller, not the sampler, chooses clipping, overflow or repeat policy.
- Walk ordered cubic segments, including the closing segment only when `closed=true`. Skip zero-length segments without renumbering authored points. Reject a contour whose total evaluated length is zero or nonfinite. Reversed traversal changes only sample order and tangent sign; it does not reverse authored point order or identity.
- The return is world position, unit forward tangent, unit clockwise normal `(-tangent.y, tangent.x)`, resolved distance, total length, source object ID and contour ID. At an interior knot use the outgoing nonzero tangent; at the end of an open contour use the incoming nonzero tangent. If a tangent cannot be resolved, reject that sample. A caller can derive a rigid orientation from the tangent; deform mode must remain a separate later operation.
- Curve length and inversion use deterministic adaptive cubic subdivision in Composition space. The implementation packet must record a finite error budget and subdivision cap, and reject when it cannot meet them. It must compare against an independent high-resolution oracle on curved fixtures. A rendered polyline approximation is not an authored replacement for the cubic.

## Exact first oracles and failure cases

An open straight contour `(0,0)→(200,0)` returns positions `(0,0)`, `(50,0)`, `(100,0)` at distances `0/50/100`, tangent `(1,0)` and normal `(0,1)`. Moving the second point to `(0,200)` returns `(0,0)`, `(0,50)`, `(0,100)` with tangent `(0,1)`. A 90-degree source transform on the original horizontal contour produces the same vertical world values without rewriting local points. Reversed traversal of the horizontal line yields `(200,0)` at distance 0 and tangent `(-1,0)`. A closed square of side 100 wraps distance 450 to the same position as distance 50, while an open line rejects distance 201.

Explicit negatives: absent path/contour ID, source Text or Image, consumer in another Composition, zero-length/nonfinite evaluated path, unsupported generated contour, nonfinite fraction/distance, and a source deletion that would orphan a retained attachment. Failure preserves authored Document, revision and History. The later consumer packet must also verify path-edit recomputation, Undo/Redo, native cold reopen, JSON-lines/API, Desktop interaction and retained editable Text/Group children. It must not assert deform, variable-font coverage or cross-Composition support from rigid first-slice evidence.

## Implementation entry boundary

Implement the sampler with its first real Text attachment caller in one bounded packet; do not add a dormant utility. Before changing native TextSource or its codec, review the exact field/version migration and deletion/reference behavior as a distinct format boundary. The present checkpoint changes neither product code nor native format. The separate R04 Collection local gate and R05-A broad font-feature gate remain in `docs/r04-collection-scope-gate.md` and `docs/r05-a-text-coverage.md`.
