## Geometry contract

For authored `direction="vertical"` Text, use DirectWrite's `DrawGlyphRun` **baseline origin X**, associated with its measured layout line/column by UTF-16 text position. Offer a column only if it contains at least one run and all of its run origins agree on one finite X coordinate. If any column is empty or ambiguous, offer no vertical baseline for that Text; do not substitute glyph bounds, frame center, line height or a guessed CJK advance. Keep the derived metric outside authored/native 0.14 state. Compose the Text path and world transforms: an axis-aligned vertical column supplies an X Snap source/target; a quarter-turn column supplies Y. Oblique columns remain outside current axis-only Snap. Reuse exact frozen/scope/visibility/follower, distance-first threshold, priority, tie, feedback, transient preview and single `TranslateObjects` release rules.

## Fixed oracle and exclusions

Use two same-font vertical-writing `H` Text objects with equal authored metrics, separated along the writing axis and with baseline X values 16 du apart by exact translation. A raw X-only 15-du body drag snaps by 16 du; feedback names `X`, `column 1 baseline`, source and target. One Undo restores the authored transform and native encode/decode retains the final one. A raw 9-du drag is 7 du from alignment and must not select Text baseline. A two-column `H\nH` vertical object with 80-du authored line spacing offers measured column 2 against a stationary column 1, with the exact delta derived from DirectWrite rather than an assumed 80-du sign. Rotated quarter-turn vertical writing may snap on Y if the composed world column is horizontal. Empty/ambiguous columns, oblique lines, non-Text sources, hidden/moving/follower/cross-scope targets, cancel and stale release offer no unintended Text baseline commit. Numeric/API translation stays exact without Snap.
